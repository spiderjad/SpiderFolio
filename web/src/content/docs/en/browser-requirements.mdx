## Supported browsers

| Browser         | Minimum version |
| --------------- | --------------- |
| Safari          | 16.4            |
| Chrome and Edge | 111             |
| Firefox         | 128             |
| Safari on iOS   | 16.4            |

This includes shop-floor phones and tablets running iOS 16.4 or later.

## What happens with an older browser

{SITE.name} never shows up half-working: if your browser doesn't meet the requirements, you'll see a simple page explaining which browser to update and to which version.

## How to check your version

In Chrome and Edge: menu, **Settings**, **About**. In Firefox: menu, **Help**, **About Firefox**. In Safari on Mac and iOS, the version depends on the operating system: update macOS or iOS.
