# Capturas

Capturas de pantalla para el README y la web pública. Se toman con la empresa demo del seed
(«Embutidos Demo S.L.», `npm run db:seed`): nunca con datos reales de personas ni de empresas.

| Archivo | Qué mostrar |
|---|---|
| `inicio.png` | Inicio del propietario: lecturas y aprobaciones pendientes, indicadores de la empresa |
| `explorador.png` | Un espacio con carpetas y archivos, con la columna de quién accede |
| `documento-controlado.png` | Un procedimiento controlado: código, versión vigente, aprobaciones |
| `permisos.png` | «Quién accede y por qué» de una carpeta |
| `bian.png` | Bian respondiendo con citas a un documento vigente |
| `planta.png` | Vista de tablet (PIN) con lecturas pendientes |

Formato: PNG de 1600 × 1000, tema claro. Para la web, la misma captura en WebP en
`web/public/capturas/<nombre>.webp` (la página de inicio solo muestra las que existen).
