# Migración a spider-ui (app y web)

Decisión (2026-11-07): spider-ui es el único sistema de diseño de la app y la web. Panel `v-*` con el
violeta de spider-ui (`--sp-primary`) como color de marca (no monocromo); acceso con `auth-*`. Ver docs/spec/diseno.md, 10.1 y 10.2.

## Etapas

1. [x] Tokens: los alias del preset (`--primary`, `--border`…) apuntan a `--sp-*`; spider-ui se
       importa desde el preset; `data-theme` sincronizado con `.dark`; acento por workspace en `hsl()`.
2. [x] `frontend/src/components/ui` (08/11/2026): botón (`v-btn-*`), input y textarea (`v-input`),
       etiqueta y mensajes (`v-label`, `v-help`, `v-error`), tarjeta (`v-card`), tabla (`v-table`), menú y
       lista del combobox (`v-menu`), diálogo (`v-dialog` con `v-card__header/body/footer`), badge
       (`v-badge`) y banner (`v-banner`), sin cambiar el comportamiento de Radix. spider-ui se importa en
       la capa `spider`, debajo de las utilidades de Tailwind: una utilidad en un `className` todavía
       ajusta un componente. El primario lleva el violeta (o el acento de la empresa) con `sf-brand`
       (`frontend/src/styles/spider-brand.css`). Quedan con los tokens del preset (sin clase de spider-ui):
       el botón ámbar, el de enlace, el badge relleno, el ámbar suave, casillas, interruptor, árbol,
       gráficos y el menú lateral.
3. [ ] Acceso (login, registro, recuperar, restablecer, invitación, verificación) con `auth-*`.
4. [ ] Web pública: quitar los degradados y checks violetas; decidir `--font-display`
       (Instrument Serif) con spider-ui.
5. [ ] Guías (es/en) donde se nombren colores y capturas con `web/scripts/capturas.ts`.

## Pendiente al cerrar el módulo (tests)

- `packages/tailwind-preset/tests/preset.test.ts` y `tokens.test.ts` siguen esperando el formato
  viejo (valores HSL en `:root`/`.dark`, `hsl(var(--x))`). Hay que reescribirlos para los alias
  `var(--sp-*)`. El contraste AA ahora lo garantiza spider-ui.
- `npm run lint` necesita `NODE_OPTIONS=--max-old-space-size=8192` en esta máquina (con el
  límite por defecto se queda sin memoria; no es un error del código).
